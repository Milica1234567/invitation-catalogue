# Invitation10 custom assets

Place the final transparent PNG artwork in this folder:

- `main-background.png`
- `rumi.png`
- `goku.png`
- `huntrix-background.png`
- `dragonball-background.png`
- `dragon.png`
- `decorative-elements.png`

Then import those files in `birthdayConfig.ts` and assign the imported URLs in `birthdayConfig.assets`. Empty asset values intentionally render the built-in CSS fallback instead of broken images.
